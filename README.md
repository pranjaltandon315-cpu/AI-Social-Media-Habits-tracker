# 🧠 AI Social Media Habit Tracker> An intelligent machine learning-powered web application designed to track, analyze, and predict social media usage patterns to help users build healthier digital habits.

## 📌 Project Overview

In today's digital age, managing screen time and understanding behavioral triggers is crucial. This project leverages exploratory data analysis (EDA) and trained machine learning classifiers to evaluate user engagement metrics, categorize usage intensity (such as heavy user detection), and deliver actionable behavioral analytics through an interactive interface.
